# Vitamin D and Tuberculosis Meta-Analysis

This directory contains the replication files for the vitamin D
meta-analysis application in the paper

> **Quantile-Only Regression: Inference and Partial Identification under Quantile Disclosure**

The application uses study-level summary statistics on serum vitamin D
levels among tuberculosis patients and controls. The corresponding
analysis is reported in Supplemental Material J of the manuscript.

## Directory contents

```text
vitaminD_meta_analysis/
├── README.md
├── vitaminD_meta_analysis.R
├── vitaminD_meta_analysis_table1.csv
└── table_vitaminD_meta.tex
```

The LaTeX table is generated by the R script.

## Software requirements

The analysis requires R and the `qonlyreg` package. Install the version
of `qonlyreg` specified in the repository-level `README.md` before
running this application.

The analysis also requires:

- `dplyr` 1.1.4
- `readr` 2.1.6
- `knitr` 1.50
- `kableExtra` 1.4.0

## Data source

The study-level summary statistics were transcribed from Table 1 of:

Nnoaham, K. E. and Clarke, A. (2008), “Low serum vitamin D levels and
tuberculosis: a systematic review and meta-analysis,” *International
Journal of Epidemiology*, 37(1), 113–119.
[https://doi.org/10.1093/ije/dym247](https://doi.org/10.1093/ije/dym247)

The input file is:

```text
vitaminD_meta_analysis_table1.csv
```

It contains the seven observational studies reported in Table 1,
including:

- study identifiers;
- the reporting format for each study;
- case and control sample sizes;
- reported medians and ranges, means and standard deviations, or means
  and ranges;
- the odds-ratio-only study reported in the source article.

The analysis script excludes the odds-ratio-only study because it does
not report the mean or quantile summaries required for this
application.

## Reproduction steps

Set the working directory to this application folder and run:

```r
source("vitaminD_meta_analysis_package.R")
```

Existing output files with the same names are overwritten.

## Output

The script creates:

```text
table_vitaminD_meta.tex
```

This is the LaTeX table reported in Supplemental Material J. The
script also prints the point estimate, standard error, conventional
confidence interval, plug-in identified region, simultaneous critical
value, and feasible confidence region to the R console.
